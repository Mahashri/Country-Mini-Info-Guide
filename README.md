# Country Mini Info Guide

A compact country-information website intended to make country facts easy to browse through a simple web interface.

## Project overview
The project is a frontend web application built with HTML, CSS and JavaScript. It is suitable for demonstrating page structure, styling and client-side interactions.

## Technology stack
- HTML5
- CSS3
- JavaScript

## Run locally
1. Clone this repository.
2. Open the project directory.
3. Open `index.html` in a modern browser, or use a local static server.

No backend setup is required unless additional services are introduced in the source.

## What to review
- Page layout and navigation.
- How country information is represented and rendered.
- Responsive behaviour across screen sizes.
- Input validation and empty-state handling, where search/filter controls are provided.

## Future improvements
- Add a documented country-data source and attribution.
- Provide search, region filters and country detail views.
- Add accessible labels, keyboard navigation and mobile layouts.
- Add automated checks for data completeness and broken links.

## Project status
Frontend demonstration. Consult the source files for the exact country fields and interactions currently implemented.
